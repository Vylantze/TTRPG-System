The DnD5e 2014 System converts SRD class and racial rules to project-specific Feature data, summarizes descriptive clauses, and stores source text for the included Class traits, Features, and all 204 Wizard spells. Extraction normalizes typography, reading order, paragraphs, and source page references; project-authored descriptions explain supporting building blocks. These adaptations are in `src/systems/dnd5e-2014`. The source document is [SRD 5.1, Creative Commons edition](https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf). The conversion is partial; its coverage manifest identifies implemented and descriptive rules.

The source PDF used for extraction has SHA-256 `2504d2a0abb0a4d491a939be4f17910a2dde0312570ab8d208080225ccf0a1f0`. Both extraction scripts check this digest before rebuilding display text or spell metadata.
