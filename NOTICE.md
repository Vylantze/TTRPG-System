# SRD 5.1 attribution

The five level-one character templates use numerical and mechanical data from the [official 2014 Starter Set character sheets](https://media.wizards.com/downloads/dnd/StarterSet_Charactersv2.pdf), © Wizards of the Coast LLC. The Starter Set document is not represented as CC-licensed. Its narrative, personality, and setting-specific background passages are linked rather than reproduced. Template names are descriptive labels; prepared-spell defaults are application choices. Additional Cleric rules and spell descriptions use the SRD 5.1 under the attribution below.

This work includes material taken from the System Reference Document 5.1 (“SRD 5.1”) by Wizards of the Coast LLC and available at https://dnd.wizards.com/resources/systems-reference-document. The SRD 5.1 is licensed under the Creative Commons Attribution 4.0 International License available at https://creativecommons.org/licenses/by/4.0/legalcode.

The DnD5e 2014 System converts SRD class and racial rules to project-specific Feature data and stores original source passages for the included Class traits, Features, and all 204 Wizard spells. Supporting building blocks use the corresponding SRD rule clauses, and spell wrappers share canonical spell text. Extraction normalizes PDF typography, reading order, and paragraph layout while preserving the source wording. Project-specific mechanical definitions and notes are separate from the displayed rules text. These adaptations are in `src/systems/dnd5e-2014`. The source document is [SRD 5.1, Creative Commons edition](https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf). The conversion is partial; its coverage manifest identifies implemented and descriptive rules.

The source PDF used for extraction has SHA-256 `2504d2a0abb0a4d491a939be4f17910a2dde0312570ab8d208080225ccf0a1f0`. Both extraction scripts check this digest before rebuilding display text or spell metadata.


The Artificer, Alchemist, Armorer, Artillerist, Battle Smith and infusion mechanical entries reference [Tasha’s Cauldron of Everything (2020)](https://www.dndbeyond.com/sources/dnd/tcoe/artificer), © Wizards of the Coast LLC. This source is not represented as CC-licensed. Its full descriptions are not reproduced; the project stores mechanical data, authored implementation notes and links. Access to linked paid content depends on the reader’s D&D Beyond account. SRD text reused by these entries remains covered by the attribution above.

Additional 2014-compatible subclass entries and Blood Hunter reference the D&D Beyond class pages and publications listed in `tools/data/dnd2014-subclasses.json`. Partner content is labelled separately from Wizards of the Coast publications. These entries contain names, mechanical data, source links and original implementation notes, without reproducing paid descriptions. Locked content is excluded. These sources are not represented as CC-licensed; the SRD attribution applies only to the reused SRD material.
