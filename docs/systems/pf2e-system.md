# PF2e System

PF2e and Pathfinder2e name the same System. Implement it after both the DnD5e 2014 System and the DnD5e 2024 System.

The [generic Feature specification](../feature-system-specification.md#pf2e-conversion-contract) contains the current conversion contract. Official PF2e content conversion awaits the source decision described there.

Status: conversion contract drafted; implementation has not started.
