# System data editor

Open **System data** in the sidebar to view and edit a loaded System. Select a data section, search for a record, and select the record to edit its JSON. Select **All records** to add or remove entries, or **Complete System** to edit the whole document.

Save or discard changes before switching records. **Validate and save** checks engine schema, references, and existing character compatibility before replacing the System in the local browser database. Failed validation leaves the previous System and characters intact. Changes increment the local semantic version automatically. Export the edited document from **Systems** to keep a portable copy; browser edits do not change bundled source files.

Build Choices are sorted by acquisition level, including nested selections. Missing selections and selections with invalid descendants have a red border and a Needs attention badge. Cleric domain spells are granted automatically at their required Cleric levels; ordinary prepared spells remain choices.
